# Country Population Viewer

An interactive web application built with the CountriesNow API that allows users to explore historical population data, trends, and global distributions.

[Visit Here](https://population-viewer-knwyh2bkbxw8bgawhwdko7.streamlit.app/)

---

## Features

- **World Population Page:**
  - Aggregated global growth metrics and key historical milestones.
  - Interactive bar charts tracking population growth over time.
  - A pie chart illustrating the population distribution of the Top 10 most populous countries compared to the rest of the world.
- **Country Insights Page:**
  - Country-specific selection dropdown.
  - Individual population growth timelines and comparative metrics.
